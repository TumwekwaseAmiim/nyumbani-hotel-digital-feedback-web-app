NYUMBANI HOTEL AI MODULE

This project now includes:
1. AI sentiment analysis
2. Automatic department detection
3. Automatic issue/category detection
4. Automatic urgency detection
5. PyTorch neural-network training script
6. TensorFlow neural-network training script
7. Deep-learning text classification starter
8. AI API integration with the web dashboard

IMPORTANT:
- The included AI API works immediately using rule-based fallback analysis.
- PyTorch and TensorFlow model training require Python packages listed in requirements.txt.
- Deep-learning accuracy improves only after you collect enough real Nyumbani feedback and train the models.
- Trained model files will be stored in /models.
